PETATOE v10.0.23 — Phase C2.1-PWA Fast Startup & Session Restore

Root causes fixed:
- App session was sessionStorage-only and disappeared after iOS terminated the PWA.
- WebAuthn/Passkey was launched automatically during normal startup.
- Mobile boot overlay appeared as a dark/black startup screen.
- Critical auth assets could run from stale cache before updating.

Main changes:
- Persistent 30-day safe application session (no password stored).
- Normal startup restores and validates the saved session first.
- Passkey now requires an explicit user click.
- Branded non-black PWA startup shell.
- Network-first caching for critical auth/startup assets.
- Release synchronized to v10.0.23.
