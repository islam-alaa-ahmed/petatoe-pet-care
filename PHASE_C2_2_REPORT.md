# PETATOE v10.0.24 — Phase C2.2
## Unified Desktop & Mobile Menu

### Root Cause
The mobile drawer was reconstructing its menu independently from a partial DOM query that only included `button[data-tab]`. This omitted canonical desktop entries driven by `data-settings-main`, rebuilt the drawer through broad navigation DOM observation, and rendered all group contents expanded instead of using the desktop grouping model.

### Implementation
- Added `navigation/navigation-schema.js` as a read-only schema adapter for the canonical desktop navigation generated by `navigation/navigation.js`.
- The schema captures the exact desktop order, groups, route attributes, labels, subtitles, permission visibility, and source button references.
- The mobile drawer now renders exclusively from this canonical schema.
- Added accordion group behavior matching the desktop grouping hierarchy.
- Added support for settings routes and special route attributes, not only `data-tab`.
- Removed the navigation subtree MutationObserver and refreshes only on canonical `petatoe:navbuilt` or permission-readiness events.
- Desktop rendering and business routing were not changed.
